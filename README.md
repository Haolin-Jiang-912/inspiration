# 社会情境判断与决策倾向量表 · 微信小程序

基于《社会比重判断与决策倾向量表》 开发。用户逐题作答后，系统按六维度评分标准累加得分，输出个性化分析与综合人物画像。

## 功能

- **逐题作答**：35 道情境判断题（Q2-Q36），每题 4 个选项，支持上/下题导航、进度条、中途退出自动保存、续答定位
- **六维度评分**：按原量表维度分组累加得分，并换算得分率
  | 维度 | 包含题号 |
  |---|---|
  | 1 社会流动与教育公平观 | 2、3、4、5 |
  | 2 劳动、青年与家庭成本观 | 6、7、12、13、14、15、17–21 |
  | 3 政府、腐败与政策过程观 | 8、9、10、11、16 |
  | 4 媒介、舆论与公共理性观 | 22–25、33、35 |
  | 5 科技、监管与外部挑战观 | 26–29 |
  | 6 国际关系与因果推理观 | 30–32、34、36 |
- **综合人物画像**：七种画像（高结构·高元认知型 / 务实改良·物质优先型 / 技术·执行型 / 结构批判·公平敏感型 / 道德·个体归因型 / 舆论敏感·身份观察型 / 平衡折中型），结果页以雷达图 + 画像卡片 + 维度详情呈现

## 评分逻辑

- 每题选项分值 0-3 分，分值基于**认知复杂度与价值观念成熟度**评定（非选项顺序固定）
  - 3 分：系统性、多因果、结构+激励+长期视角
  - 2 分：有结构意识或关键洞察，但覆盖不完整
  - 1 分：偏单一因果、道德化或只看短期
  - 0 分：过度简化、个体道德归因、忽视制度激励
- 维度高低判定：得分率 ≥75% 为高、50%–75% 为中、<50% 为低（原文档的"满分约 XX"阈值统一换算为得分率，逻辑保持一致）
- 画像判定：按"高结构 → 道德归因 → 平衡折中 → 舆论敏感 → 技术执行 → 结构批判 → 务实改良 → 兜底"的优先级，依据各维度得分率组合匹配

> 注：原文档维度分组未包含第 13 题（大规模民营企业倒闭，重编号后为第 12 题），因其内容属于劳动与经济范畴，本程序将其归入维度 2，并在计算中保持自洽（维度 2 满分相应为 32 分）。

## 项目结构

```
wechat-miniprogram/
├── app.js / app.json / app.wxss    # 全局配置与样式
├── project.config.json             # 开发者工具项目配置
├── sitemap.json
├── data/
│   ├── questions.js                # 35 道题目、选项、分值、思维注释
│   └── profiles.js                 # 六维度定义 + 七种画像文案
├── utils/
│   └── scoring.js                  # 评分累加与画像判定算法
└── pages/
    ├── index/                      # 欢迎页（量表说明 + 开始答题）
    ├── quiz/                       # 答题页（逐题作答 + 进度条）
    └── result/                     # 结果页（雷达图 + 画像 + 维度详情）
```

## 运行方式

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具 → 导入项目 → 选择本目录 `wechat-miniprogram`
3. AppID 已设为测试号（`touristappid`），可直接以游客模式预览；如需真机体验，请替换为自己的小程序 AppID
4. 编译运行即可

## 数据说明

- 全部题目、选项分值、思维注释、维度分组、画像文案均提取自用户提供的《参考答案以及注释》文档，未做主观改动
- 答题记录保存在本地缓存（`quiz_answers`），重新测试会清空记录
- 测评结果仅基于选项分布生成，仅供自我认知与讨论参考
